# Week-end des 80 ans

Mini-site mobile pour GitHub Pages.

## Publication
1. Creez un depot GitHub public.
2. Ajoutez index.html a la racine du depot.
3. Dans Settings > Pages, choisissez Deploy from a branch.
4. Selectionnez main et /(root), puis Save.

Le site sera ensuite disponible via l adresse GitHub Pages affichee par GitHub.
